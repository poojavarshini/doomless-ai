# Three-minute demo script

## 0:00–0:30 — Problem

Open the hosted beta. Say: “Feeds show likes, not cognitive value. DoomLess makes attention cost visible before you spend it.” Select the Practical Learning and Clickbait samples and compare the decisions—not just the scores.

## 0:30–1:20 — Honest live extension

Open Instagram Reels with the unpacked extension. Show that analysis is off by default and history is local. Enable analysis and hover for 800 ms. The fixed-size label should communicate one score, one content type, and one short decision. When evidence is insufficient, show the neutral `--/100` limited-analysis state without technical errors.

## 1:20–2:05 — Decision-first demo

Enable the clearly labeled Demo mode. Load an educational fixture and then positive entertainment. Point out that entertainment can receive “Watch for fun” without pretending to teach. Show that neither label needs scrolling or expansion.

## 2:05–2:35 — Behavior dashboard

Open the popup. Show useful versus skip decisions, average score, attention saved, useful content consumed, clickbait exposure, addiction-risk exposure, top content, seven-day score, and local recent decisions. Change interests and explain that only Personal Relevance is personalized.

## 2:35–3:00 — Close

Return to the public beta and say: “DoomLess is not an internet morality score. It is an evidence-aware decision layer that separates content value, personal relevance, and behavioral risk.”

## Screenshot/GIF guidance

Capture at 1440×900 with personal details hidden. Required shots: green compact decision, gray limited-analysis state, minimized label, privacy settings, and dashboard KPIs. For a GIF, record hover → compact decision → minimize → popup in under 12 seconds. Never show API keys, private Reels, usernames, messages, or notifications.
