# Three-minute demo script

## 0:00–0:30 — Problem

Open the hosted web demo. Say: “Feeds show likes, not cognitive value. DoomLess makes attention cost visible before you spend it.” Show one high-value and one scroll-bait example.

## 0:30–1:25 — Live extension

Open Instagram Reels with the unpacked extension installed. Open DoomLess settings and point out that analysis is off by default and history is local. Enable analysis. Hover over a public Reel for 800 ms or press Analyze. While loading, explain that only caption and visible metadata are being used. Expand the label and show seven explained categories, confidence, missing information, useful seconds, and the formula link.

## 1:25–2:05 — Action and personalization

Choose Save useful or Skip. Open the extension popup to show the local record and estimated attention saved. Change interests in settings, then analyze a clearly aligned Reel and explain that only Personal Relevance is personalized.

## 2:05–2:35 — Reliability

Turn off the local API or use airplane mode and revisit an analyzed Reel to show cached fallback. Visit an uncached Reel to show a retryable error. State clearly: DoomLess does not scrape media or pretend it has a transcript.

## 2:35–3:00 — Close

Return to the web demo. Say: “DoomLess is not an internet morality score. It is a decision layer that separates content value, personal relevance, and attention risk.” End on the dashboard or nutrition label.

## Screenshot/GIF guidance

Capture at 1440×900 with browser bookmarks and personal account details hidden. Required shots: collapsed overlay, expanded explainability, privacy settings, popup metrics, and demo fallback. For a GIF, record Analyze → expand → Save → popup in under 12 seconds. Never show an API key, private Reel, username, messages, or notifications.
